# Décisions du projet (ADR)

ADR veut dire « Architecture Decision Record » : une fiche courte qui dit **ce qu'on a décidé, pourquoi, et ce que ça change**.

Une décision n'est officielle que quand son fichier est fusionné dans `main`.
