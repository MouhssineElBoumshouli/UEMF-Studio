# Architecture Decision Records (ADR)

This directory stores durable project decisions.

Use an ADR when a decision has long-term consequences, for example:
- architecture;
- state management;
- backend technology;
- database;
- authentication;
- API style;
- branching/merge policy;
- major dependency choice;
- security model.

## Status values
- Proposed
- Accepted
- Superseded
- Rejected

Do not rewrite history silently. If a decision changes, create a new ADR that supersedes the old one.
