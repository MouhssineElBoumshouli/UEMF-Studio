## Les règles en bref

- GitHub est la source officielle.
- On ne code jamais directement sur `main`.
- Une tâche = une issue = une seule personne assignée.
- Une fonctionnalité = une branche.
- Tout passe par une Pull Request avant d'entrer dans `main`.
- Les IA (Claude, Claude Code, Codex) peuvent écrire du code. Elles ne décident pas de l'architecture.
- Toute décision importante prise avec l'aide d'une IA est écrite dans `docs/decisions/`.
