Les règles sont les mêmes pour tous les agents. Elles sont dans [CLAUDE.md](CLAUDE.md) — lis ce fichier et suis-le.

Résumé :
- Jamais de commit sur `main`. Une branche par issue.
- Pas de travail sans issue.
- Tout passe par une Pull Request. Tu ne fusionnes pas.
- Tu ne décides pas de l'architecture ni des dépendances : tu proposes, l'équipe décide (ADR dans `docs/decisions/`).
- Pas de code Flutter tant que la structure du projet n'est pas décidée.
